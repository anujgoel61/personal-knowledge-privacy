Privacy Policy

Personal Knowledge Wiki is a private, user-controlled system that creates a searchable local index from accounts the user explicitly connects.

Who operates this application

Personal Knowledge Wiki is operated by Anuj Goyal for personal and household use. It is not offered as a public software service.

Google data the application accesses

The application requests only the read-only Google permissions shown on the Google consent screen. For Gmail, this includes permission to view email messages and settings. It cannot send, modify, or delete email.

How Google data is used

  • To create and maintain a private, searchable personal knowledge index.
  • To extract text and metadata needed for local search and retrieval.
  • To refresh the index incrementally so it reflects newly available content.

Google user data is not used for advertising, profiling, or sale.

Storage and protection

Synced content is stored on computers controlled by the user. OAuth credentials are stored in the operating system's protected credential store. Replicas, when enabled by the user, are encrypted before transfer.

AI-assisted retrieval

When the user deliberately asks a connected AI client a question, the local knowledge service may return relevant excerpts to that client. Those excerpts are then handled according to the privacy and data-control settings of the AI service the user chose to invoke. The application does not send Google data to an AI service on its own.

Sharing

The application does not sell Google user data or make the private index publicly available. Data is disclosed only when directed by the user, required to provide a user-invoked integration, or required by law.

Retention and deletion

Local copies remain until the user deletes them. The user can stop future access by revoking the application's permission in their Google Account, and can delete locally stored content and credentials at any time.

Changes to this policy

This policy may be updated when the application's data practices change. The effective date below will be updated when material changes are published.
